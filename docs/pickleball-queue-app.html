How the queue works

Every player who checks in takes a fixed spot in line — no re-shuffling, no favorites. When a court opens, the next group is drafted according to the priority mode your club chooses:

  • First in Line — longest wait plays next
  • Less Played First — fewest games today goes first
  • Winners / Losers queues — winners meet winners, with configurable re-entry (front, back, or smart position)

Everyone can see exactly where they stand — the queue is shown on any shared screen or on each player's phone.

More than a line — a matchmaker

The queue decides when you play; matchmaking decides how good the game is:

  • Skill-balanced teams using per-club ratings (everyone starts at 1450)
  • Modes: Pro Pick, Casual, Competitive, Standard, Social, or full Manual Match
  • Fixed Duo — lock a pair that is never split
  • Avoid player — keep chosen players off the same team
  • Rotating partners so nobody plays with the same people all night

Ratings, leaderboards, DUPR

Every scored match moves club ratings, feeds the leaderboard, and builds each player's profile — partners, rivals, and clutch record. Completed matches export as a DUPR-ready CSV for bulk upload.

Built for multi-organizer sessions

Admins and moderators can run the same session from their own devices — adds, check-outs, scores, and resets sync safely in real time. Reset actions are authoritative: a device holding stale data can't overwrite the active session.
